# Student Pass or Fail Predictor

A beginner project that explores student results and predicts a student's chance of passing using a classification model.

## Files

- `Lab 2 - Student Pass or Fail (Beginner).ipynb` — explores the data and trains the model.
- `student_app.py` — Streamlit app for making predictions.

## Run the app

1. Install the required packages: `pip install streamlit pandas joblib scikit-learn`
2. Run the notebook first to create `student_model.pkl` and `student_model_columns.pkl` in this folder.
3. Start the app: `streamlit run student_app.py`
